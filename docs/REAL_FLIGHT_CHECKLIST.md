# SwarmGod — Real-flight checklist

> เช็กลิสต์นี้มีเฉพาะสิ่งที่ผู้ควบคุมต้องตรวจด้วยตัวเองก่อนบิน
> รายการที่โปรแกรมตรวจได้ เช่น GPS, telemetry, battery, mTLS, token, geofence,
> separation, Head/Leader และ command path ให้ปุ่ม SYSTEM TEST ตรวจแทน

## ก่อนบินจริง

- [ ] ใบพัด / มอเตอร์ / โครงโดรน ไม่มีความเสียหาย และติดตั้งแน่น
- [ ] แบตเตอรี่โดรนทุกลำล็อกแน่น ไม่มีบวม ร้อน หรืออาการผิดปกติ
- [ ] พื้นที่ Takeoff / Landing โล่ง ไม่มีคน สัตว์ หรือสิ่งกีดขวางในเขตอันตราย
- [ ] รีโมทและสวิตช์ควบคุมอยู่ตำแหน่งถูกต้อง และพร้อมรับช่วงควบคุมทันที
- [ ] ตำแหน่งและทิศทางของโดรนแต่ละลำบนแผนที่ตรงกับของจริง
- [ ] ทดสอบ ARM → DISARM และยืนยันว่าแต่ละลำตอบสนองถูกต้อง
- [ ] ทดสอบ Servo A / B หรืออุปกรณ์ปล่อยของก่อนใช้งานจริง
- [ ] ผู้ควบคุมยืนยันว่า พร้อมบิน และไม่มีบุคคลอยู่ในเขตอันตราย

ครบ 8/8 จึงถือว่า CHECKLIST PASS
