## 1. ภาพรวมระบบ

SwarmGod เป็น Ground Control Station สำหรับควบคุมฝูงโดรน (MAVLink) หลายลำพร้อมกัน
แบ่งเป็น 3 ชั้น:

```
┌──────────────────────────────────────────────────────────┐
│ ชั้น 1 — COCKPIT (Python / PyQt5)                        │
│   หน้าจอควบคุม: fleet cards, แผนที่ 2D/3D, video, คำสั่ง │
│   + Field Tablet (เว็บสำหรับแท็บเล็ตสนาม)               │
│   ไม่แตะ MAVLink โดยตรง — ส่ง intent ผ่าน gRPC           │
├──────────────────────────────────────────────────────────┤
│ ชั้น 2 — CORE (Go)                                       │
│   รับ MAVLink จากโดรน, บังคับ Safety Envelope             │
│   จัดขบวน Swarm, บันทึก Audit Log ทุกคำสั่ง              │
│   gRPC over mTLS — UI ส่งผิดหรือโดนดัดแปลงก็ข้ามไม่ได้  │
├──────────────────────────────────────────────────────────┤
│ ชั้น 3 — VEHICLES                                        │
│   ArduPilot FC จริง / SITL (จำลอง)                       │
│   MAVLink 2.0 signed (HMAC)                              │
└──────────────────────────────────────────────────────────┘
```

**หลักการออกแบบ:**
- **Core owns safety** — การตัดสินใจอันตรายบังคับที่ Go core ไม่ใช่ที่ UI
- **Fail-safe by default** — ไม่แน่ใจ = ไม่ทำ, link ขาด = failsafe อัตโนมัติ
- **UI คือกระจก ไม่ใช่สมอง** — Python แค่แสดงผล + ส่ง intent
- **ทุก command ถูก audit** — append-only log ก่อนส่งออกทุกครั้ง

## 2. การติดตั้งและเตรียมเครื่อง

### วิธีง่ายที่สุด
ดับเบิลคลิก **`SETUP.bat`** — ตรวจและติดตั้งทุกอย่างที่ขาด (Go, Python, dependencies,
certs, build core) ในคลิกเดียว รันซ้ำได้ปลอดภัย

### ติดตั้งเอง (manual)
```
winget install GoLang.Go Google.Protobuf
cd backend && go build ./...
cd frontend && pip install -r requirements.txt
```

### เตรียมล่วงหน้าที่บ้าน (ก่อนออกสนาม)

| เตรียม | รายละเอียด |
|--------|-----------|
| **ฮาร์ดแวร์** | โดรนแต่ละลำมี Flight Controller + GPS + ตัวส่ง telemetry (WiFi/วิทยุ/4G) |
| **เครือข่าย** | โดรนทุกลำ + GCS อยู่วงเดียวกัน, จด **IP:port** แต่ละลำ (เช่น `192.168.40.1:5760`) |
| **certs** | รัน launcher หนึ่งครั้ง (สร้าง mTLS + signing key) หรือ `go run ./cmd/gencerts` |
| **MAVLink signing** | ถ้าจะเปิด strict — เอา `certs/mavlink_key` ไปตั้งที่ FC ให้ตรงกัน |
| **FC failsafe** | ตั้งที่ FC: `FS_GCS_ENABLE=1`, `FS_THR_ENABLE`, `BATT_LOW/CRT_VOLT` |
| **แผนที่ offline** | เปิดโปรแกรมที่บ้าน กด **CACHE THIS AREA** เก็บ tiles พื้นที่ปฏิบัติงาน |

## 3. เริ่มต้นใช้งาน (Launcher)

ดับเบิลคลิก **`START_SWARMGOD.bat`**

1. **เอาเครื่องหมาย "ใช้ SITL" ออก** ถ้าจะต่อโดรนจริง (ทิ้งไว้ = เปิดจำลอง)
2. Launcher จะ: สร้าง certs → build core → เปิด core → (เปิด SITL ถ้าติ๊ก) → เปิด cockpit
3. รอ checklist ขึ้น "พร้อมใช้งาน" แล้วหน้าต่าง cockpit จะเด้งมา
4. ปุ่ม **STOP ALL** ปิดทุกอย่างในคลิกเดียว

### โหมด Production (โดรนจริง)
ตั้ง environment ก่อนเปิด launcher:
```powershell
$env:SWARMGOD_PROFILE="production"
$env:SWARMGOD_HOME_LOC="13.7563,100.5018,0,0"  # lat,lon,alt,heading
$env:SWARMGOD_TOKEN="<ค่าที่ swarmadmin แสดง>"
```
Production จะไม่ยอม start ถ้า cert/CA โหลดไม่ได้, ไม่ได้ตั้ง HOME_LOC,
ไม่ได้เปิด strict signing หรือ signing key สั้นกว่า 32 ไบต์

## 4. หน้าจอ Cockpit — ส่วนประกอบหลัก

```
┌──────────────────────────────────────────────────────────┐
│ Top Bar: [CORE] [LINK OK] [โหมดบิน] [UI/REMOTE] [⚙] [?]│
├─────────────┬────────────────────────────┬───────────────┤
│ แผงซ้าย     │       แผนที่ 2D/3D        │  แผงขวา       │
│ • การ์ดโดรน │  หมุดโดรน + เส้นทาง       │  • FLIGHT     │
│ • IP / CONN │  Geofence + Waypoint      │  • SWARM      │
│ • SCAN      │  คลิก = GOTO/วางจุด       │  • WAYPOINT   │
│             │                            │  • SAFETY     │
│             ├────────────────────────────┤  • ฯลฯ        │
│             │ การ์ดล่าง (ลำที่เลือก)     │               │
│             │ ALT/SPD/HDG/BAT/SERVO     │               │
└─────────────┴────────────────────────────┴───────────────┘
│ Mission Log                                              │
└──────────────────────────────────────────────────────────┘
```

### แถบบน (Top Bar)
- **CORE** — สถานะ Go core (เขียว = พร้อม)
- **LINK OK** — กำลังรับ telemetry อยู่
- **ป้ายโหมดบิน** — แสดงลำดับความสำคัญ: RTL > Waypoint > Swarm > Flight ปกติ
- **UI / REMOTE** — สวิตช์ควบคุม (ดูหัวข้อ 17)
- **⚙** — เมนูตั้งค่า
- **?** — เปิดคู่มือ (Help Dialog)

### แผงซ้าย
- การ์ดโดรนแต่ละลำ: ชื่อ, badge สถานะ (OFFLINE → CONNECTING → READY → FLYING),
  SAT/BAT/MODE/ALT/HDG
- ปุ่มดาว ☆ = ตั้ง Head, ปุ่ม PING / DISC / DEL
- ช่อง IP + Port สำหรับเชื่อมต่อ

### การ์ดล่าง
แสดงรายละเอียดลำที่เลือก: โมเดลโดรน, link quality, battery, คำสั่งรายลำ
- กด ✎ เพื่อแก้ชื่อโดรน
- ช่อง ALT/SPACING สำหรับตั้งค่ารายลำ

## 5. เชื่อมต่อโดรน

1. ช่อง IP บนซ้าย พิมพ์ **IP ของลำที่ต้องการ** (เช่น `192.168.40.1`) + PORT (`5760`) → กด **CONN**
   - หรือกด **SCAN** เพื่อหาพอร์ต MAVLink ในวง LAN แล้วเลือกใส่
   - IP ที่เคย add จะถูกจำใน SQLite (`~/.swarmgod/fleet_ips.db`) — เปิดครั้งหน้าขึ้นเอง
   - IP ซ้ำกับลำอื่นจะถูกปฏิเสธพร้อม toast เตือน
2. การ์ด **UAV_1** โผล่ทางซ้าย → badge จะไล่: `OFFLINE → CONNECTING → READY`
3. ทำซ้ำสำหรับลำ 2, 3, … (เปลี่ยน IP/port เช่น `192.168.40.2:5760`)
4. บนการ์ด: **PING** ทดสอบลิงก์ · **DISC** ตัดการเชื่อม · **DEL** ลบออกจากฝูง
5. เมนู **SAVE / EXPORT / LOAD** เก็บหรือย้ายการตั้งค่า cockpit (JSON)

**โปรโตคอล:** TCP หรือ UDP (MAVLink) — ปกติโดรนจริงเปิด TCP `<ip>:5760`
ถ้าใช้ MAVProxy/ตัวรีเลย์กลาง: เชื่อมไปที่ port ที่รีเลย์เปิดให้

## 6. ตรวจสอบ Telemetry ก่อนบิน

ดูที่การ์ดแต่ละลำ ต้องครบ:

| ตัวชี้วัด | เกณฑ์ผ่าน |
|-----------|----------|
| **badge** | READY (เขียว) |
| **SAT** | ≥ 6 ดวง + 3D fix |
| **BAT** | ≥ 50% (core ห้าม arm ถ้า < 25%) |
| **MODE / ALT / HDG** | ขึ้นค่าจริง |
| **หมุดบนแผนที่** | ตรงตำแหน่งจริง |

### อ่านหน้าจอ

- ป้าย **CORE** บนแถบบน = core พร้อมทำงาน
- **LINK OK** = cockpit กำลังรับ telemetry
- แถบ **LAT/LNG** ใต้แผนที่แสดงพิกัด ชี้เมาส์ค้างเพื่อดูค่าเต็ม

## 7. Pre-flight Test & Checklist

### 7.1 ปุ่ม SYSTEM TEST

เครื่องตรวจอัตโนมัติ ตรวจเฉพาะข้อที่มีผลต่อความปลอดภัยจริง:

| กลุ่ม | ตรวจอะไร | ไม่ผ่าน |
|---|---|---|
| **LINK** | core + mTLS + token + profile/HOME_LOC (ถ้า production) | บล็อก |
| | telemetry สดภายใน 3 วิ | บล็อก |
| | สวิตช์ CONTROL อยู่ที่ UI | บล็อก |
| | คุณภาพ datalink ≥ 40% | เตือน |
| **READY** | GPS 3D fix + SAT ≥ 6 ทุกลำ | บล็อก |
| | BAT ≥ 40% | บล็อก |
| | ทุกลำ disarm อยู่บนพื้น | บล็อก |
| | มีพิกัดจริง (ไม่ใช่ 0,0) | บล็อก |
| **SEPARATION** | ระยะห่างบนพื้นทุกคู่ ≥ ค่ากันชน | บล็อก |
| **CONFIG** | TAKEOFF ALT สมเหตุผล (> 60m = เตือน) | เตือน |
| | RTL (base ≥ 10m, gap ≥ 3m) · Geofence | เตือน |
| | Head ตั้งแล้ว + ออนไลน์ (เมื่อบินหลายลำ) | บล็อก |
| **COMMAND** | สั่ง HOLD แล้ว core ตอบรับ | เตือน |
| | สั่ง GUIDED แล้ว FC รายงานกลับภายใน 8 วิ | บล็อก |

ข้อ COMMAND สุดท้ายคือหัวใจ — พิสูจน์เส้นทางเต็มวง
`cockpit → core → MAVLink → FC → telemetry กลับมา`

#### ติ๊ก "ถอดใบพัดแล้ว" (Bench Test)

ปลดล็อกอีก 2 ข้อที่สั่งของจริง:
- **TAKEOFF ที่ไม่ยืนยันถูกปฏิเสธ** — ยิง Takeoff(confirmed=false) ถ้า core ยอมรับ = ไม่ผ่าน
- **ARM → DISARM** — พิสูจน์ว่าผ่าน pre-arm ของ FC จริง

> ห้ามติ๊กถ้าใบพัดยังอยู่ — มอเตอร์จะหมุนจริง

### 7.2 ปุ่ม CHECKLIST

อ่าน `REAL_FLIGHT_CHECKLIST.md` แสดงเป็น checkbox ในโปรแกรม
ติ๊กเองตามที่ตรวจจริงในสนาม (ข้อพวกนี้เครื่องตรวจแทนไม่ได้)
สถานะเก็บที่ `~/.swarmgod/preflight_checklist.json`

รายการ:
- [ ] ใบพัด/มอเตอร์/โครง ไม่มีความเสียหาย ติดตั้งแน่น
- [ ] แบตโดรนทุกลำล็อกแน่น ไม่บวม/ร้อน
- [ ] พื้นที่ Takeoff/Landing โล่ง ไม่มีคน/สัตว์/สิ่งกีดขวาง
- [ ] รีโมทและสวิตช์อยู่ตำแหน่งถูกต้อง พร้อมรับช่วงทันที
- [ ] ตำแหน่งโดรนบนแผนที่ตรงกับของจริง
- [ ] ทดสอบ ARM → DISARM แต่ละลำตอบสนองถูกต้อง
- [ ] ทดสอบ Servo A/B หรืออุปกรณ์ปล่อยของ
- [ ] ผู้ควบคุมยืนยันว่าพร้อมบิน ไม่มีบุคคลอยู่ในเขตอันตราย

### 7.3 ถ้ายังไม่ได้เทสแล้วสั่ง TAKEOFF

ทุกทางที่ทำให้โดรนลอย (ปุ่ม TAKEOFF / SWARM TAKE OFF / AUTO TAKEOFF ก่อน EXECUTE ROUTE)
จะถามยืนยันก่อน พร้อมบอกว่าขาดอะไร

## 8. การเลือกโดรนและกลุ่ม

| วิธีทำ | ผลลัพธ์ |
|--------|---------|
| คลิกการ์ดฝั่งซ้าย 1 ครั้ง | เลือกลำเดียว (ยกเลิกลำอื่น) |
| คลิกรายการในการ์ด 'โดรน' บน Map 3D | เลือกลำนั้น + เปิดรายละเอียด |
| Ctrl + คลิก | เพิ่ม/เอาลำออกจากชุด (เลือกได้หลายลำ) |
| ปุ่ม FLEET (หมวด FLIGHT) | เปิด = เลือกทุกลำ · ปิด = ล้างทั้งหมด |

เลือกเองจนครบทุกลำ → ปุ่ม FLEET จะติดเองอัตโนมัติ (sync กันตลอดเวลา)
กดปุ่มดินสอข้างชื่อเพื่อแก้ชื่อโดรน

### กลุ่มโดรน

- แถว **กลุ่ม** เหนือรายการโดรนมีชิป **ทั้งหมด / 1–6** (เช่น `1·2` = "กลุ่ม 1 มี 2 ลำ")
- คลิกชิปเพื่อเลือกทั้งกลุ่ม, Ctrl+คลิกเพื่อเพิ่มอีกกลุ่ม
- กำหนดกลุ่มด้วย Ctrl+เลข 1–6, คลิกขวาที่ชิป หรือคลิกขวาที่การ์ดโดรนแล้วเลือก "กลุ่ม"
- โดรนหนึ่งลำอยู่ได้กลุ่มเดียว, ลำที่ offline จะถูกข้ามพร้อมแจ้งเตือน

## 9. Head / Leader (หัวขบวน)

- กดดาว ☆ บนการ์ด หรือปุ่ม **SET HEAD** ที่การ์ดล่าง → ต้องยืนยันใน pop-up เสมอ
- ถ้าหัวขบวนหลุดการเชื่อมต่อ → ระบบเลื่อนลำถัดไปขึ้นเป็นหัวให้อัตโนมัติ (Auto-Reassign)
- **ห้ามเปลี่ยน Head** ตอนกำลัง RTL, TAKEOFF/LANDING, หรือ Swarm เคลื่อนที่อยู่
  → ปฏิเสธทันที (ขึ้น toast + banner แดง) เพื่อกันโดรนชนกัน
  รอจนโดรนนิ่งก่อนค่อยเปลี่ยน

## 10. การบิน — Takeoff, RTL, Land, Hold

### Takeoff
สั่งได้ทั้ง **รายลำ** (กดที่การ์ดแต่ละลำ) และ **ทุกลำที่เลือก** (แผงขวา):

| โหมด | พฤติกรรม |
|------|---------|
| All | ทุกลำที่เลือกขึ้นบินพร้อมกัน |
| Sequential | หัวขบวนขึ้นก่อน แล้วลูกทยอยตาม (~2.5 วิ/ลำ) |
| TAKE OFF ในแผง Swarm | แนบ Form Up ให้อัตโนมัติ |

ความสูงดีฟอลต์ **20 m** ทุกลำ — ตั้งรายลำได้ที่ช่อง ALT ในการ์ดล่าง

### RTL (กลับฐาน) — แยกชั้นความสูงกันชน
- ตั้งค่าที่หน้า SAFETY & SYSTEM: **RTL BASE ALTITUDE** + **RTL MIN GAP**
- แต่ละลำไต่ระดับ → บินกลับ home ที่ความสูงของตัวเอง → ลงจอด อิสระ

### Return + Land (ทั้งฝูง)
- กด **RETURN + LAND** ในแผง SWARM:
  1. ทุกลำบินไปเหนือจุดลงแยก รอบ home (ห่างกัน ≥ MinSeparation 5m)
  2. ลงจอดทีละลำ ตัวแม่ก่อน ลูกตามลำดับ

### Hold
- กด **HOLD** = ค้างที่เดิม ความสูงเดิม ใน GUIDED — สั่งต่อได้ทันที
- **ไม่ใช้** LOITER/ALT_HOLD/POSHOLD เพราะสติ๊กคันเร่งอยู่ตำแหน่งต่ำสุด → โดรนร่วง
  (เดิมใช้ LOITER จึงเคยมีอาการ "กดยกเลิกแล้วโดรนตก" — ตอนนี้แก้แล้ว)
- ถ้าลำนั้นยังไม่มีพิกัด GPS → สั่งความเร็ว 0 แทน

### Land
- กด **LAND** = ลงจอดตรงตำแหน่งปัจจุบัน

## 11. บังคับตรง — Direct Flight (GOTO)

1. **ปลดล็อก** ปุ่มรูปโดรนบนแผนที่ก่อน (โหมดสั่งบินค้าง กดซ้ำเพื่อปิด)
2. **คลิกแผนที่ 2D** หรือ **ดับเบิลคลิกพื้นใน 3D** = บินไปจุดนั้น
3. **GO TO ALT** = เปลี่ยนความสูงโดยไม่ย้ายตำแหน่ง

ลำดับที่ระบบเช็คตอนคลิกแผนที่:
1. Waypoint Mode เปิด? → วางจุด
2. Tactical Tool เปิด? → วาดแผน
3. Geofence Draw เปิด? → วาดรั้ว
4. ไม่มีอะไรเปิด → สั่งบินตรงไปจุดนั้น (Direct Flight)

## 12. Waypoint Route Planning (เส้นทางบิน)

### เปิดโหมด Waypoint
เปิดสวิตช์ **Waypoint Mode** ในแผงขวา → คลิกแผนที่เพื่อวางจุด (ไม่บินทันที)

### GROUPED vs SEPARATE

| โหมด | พฤติกรรม |
|------|---------|
| **GROUPED** | วางเส้นทางเดียว ทุกลำบินตามขบวน (ตัวแม่ตามเส้น ลูกเกาะตาม) |
| **SEPARATE** | วางเส้นทางแยกรายลำ เลือกลำ → วางจุดของลำนั้น |

สลับ GROUPED ↔ SEPARATE จะล้างจุดที่วางค้างทิ้ง (คนละรูปแบบ เก็บต่อไม่ได้)
เปิด Swarm ขณะ SEPARATE → บังคับกลับเป็น GROUPED ทันที

### Execute Route
- กด **EXECUTE ROUTE** เพื่อสั่งบินตามเส้นทาง
- ถ้าโดรนยังไม่ TAKEOFF → ระบบถาม + สั่ง TAKEOFF ให้ (รอไม่เกิน 90 วิ)
- ถ้ามี Servo A/B ในเส้นทาง → ต้องยืนยันรายละเอียดก่อน

### Waypoint Actions (A/B)
คลิกขวาที่จุด Waypoint → เลือก **ปล่อย A (CH7) / ปล่อย B (CH8) / ไม่ทำอะไร**
จุด A/B จะแสดงสีต่างกัน เมื่อถึงจุด ระบบ HOLD → ปล่อย → รอ 2 วินาที → ไปจุดถัดไป

### ปุ่มควบคุม
- **Undo** — ลบจุดล่าสุด
- **Clear** — ล้างจุดทั้งหมด (ถามยืนยัน)
- **Cancel Nav** — ยกเลิกเส้นทางที่กำลังบิน + สั่ง Hold

### PRE-FLIGHT SUMMARY
กล่องนี้แสดงเฉพาะ **"แผนที่จะมีผลจริงตอนบิน"** — ภาพนิ่งของสิ่งที่ *กำลังจะสั่ง*
เพื่อรีวิวก่อนกด Take off จริง:

- ลำ/กลุ่มที่เลือก (SELECTED), หัวขบวน (HEAD)
- โหมด/ความสูง TAKEOFF (TAKEOFF MODE / TAKEOFF PLAN)
- Waypoint Mode + GROUPED/SEPARATE, จำนวนจุด, จุดปล่อยของ A/B (WAYPOINT A/B)
- กลุ่มและลำดับ WAVE, RETURN + LAND, RTL CONFIG
- ALT/SPACING รายลำ

> **ไม่ใช่ประวัติเหตุการณ์** — การกดปุ่ม/การยกเลิก/ผลลัพธ์/พรีเทส/เช็คลิสต์
> ไปไล่ดูย้อนหลังที่ **Mission Log** (หมวด COMMAND) แทน กล่องสรุปจึงเหลือแต่แผน
> ที่กำลังจะสั่ง ไม่รกด้วยรายการที่ทำไปแล้ว

## 13. Swarm — จัดขบวนบินเป็นฝูง

### รูปแบบขบวน
| ชื่อ | ลักษณะ |
|------|--------|
| WEDGE | ลิ่ม (V shape) |
| LINE | หน้ากระดาน |
| COLUMN | แถวตอน |
| DIAMOND | เพชร |
| ECHELON | ทแยง |

### วิธีใช้
1. ให้ทุกลำ **takeoff ขึ้นก่อน** (badge FLYING ครบ)
2. เลือก **รูปขบวน** + ตั้ง **SEP** (ระยะห่าง) → กด **FORM UP**
3. ลูกจัดตำแหน่งเกาะตัวแม่ + หันหน้าตามตัวแม่
4. เปลี่ยนรูป/ระยะระหว่างบินได้ — กด FORM UP ใหม่

### ข้อจำกัดความปลอดภัย
- SEP ใกล้เกินขั้นต่ำ → เตือนสีเหลือง + ไม่ให้ตั้ง
- Core คำนวณระยะจริง**ทุกคู่** ถ้ามีคู่ใกล้กว่า MinSeparation (5m) → ปฏิเสธ
- หัวขบวนหาย → เลื่อนลำถัดไปเป็นแม่อัตโนมัติ

> **SPACING** บนการ์ดล่าง = ระยะห่างจากลำหน้าขณะบินเป็นขบวน
> ไม่ใช่ความสูง และไม่ใช่ระยะทางไปยังจุด GOTO

---

## 14. กลุ่มโดรนและ WAVE (ส่งบินเป็นรอบ)

### WAVE คืออะไร
ในโหมด **WAYPOINT ROUTE / GROUPED** เปิด WAVE แล้วเลือกอย่างน้อย 2 กลุ่ม
เมื่อกด **EXECUTE ROUTE** ระบบจะส่งกลุ่มตามเลข 1 → 2 → 3 กลุ่มละรอบ

### การทำงาน
1. กลุ่ม 1 บินตามเส้นทาง → กลับฐาน → ลงจอด → Disarm
2. กลุ่ม 1 Disarm ครบ → กลุ่ม 2 เริ่ม (ถ้ายังอยู่พื้นจะถาม TAKEOFF)
3. ทำซ้ำจนครบทุกกลุ่ม
4. ถ้าเกิน 5 นาที → ระบบหยุดทั้ง WAVE

### ยกเลิก WAVE
- กด **ยกเลิกเวฟ**, Cancel Nav, ปิด WAVE หรือ E-STOP

> WAVE ไม่เปลี่ยนพฤติกรรมของปุ่ม TAKE OFF, RTL, LAND, GOTO, ARM, HOLD, E-STOP
> แต่ EXECUTE ROUTE สามารถสั่ง TAKEOFF ให้กลุ่มที่ยังอยู่พื้นได้ — หลังผู้ใช้ยืนยันเท่านั้น

## 15. Servo A / B (กลไกปล่อยของ)

ปุ่ม **A** = CH7 · **B** = CH8 (หมวด FLIGHT ฝั่งขวา)
สั่งผ่าน `RC_CHANNELS_OVERRIDE` ใช้ร่วมกับสวิตช์บนรีโมทได้

### สถานะปุ่ม

| หน้าปุ่ม | ความหมาย |
|---------|---------|
| **A ⌛** | กำลังเตรียมช่องให้เอง (อัตโนมัติหลังเชื่อม) |
| **A** | พร้อมใช้งาน — กดเพื่อเปิด |
| **A ⋯** | สั่งแล้ว รอ FC ตอบรับ (ส่งซ้ำทุก 0.5 วิ ไม่ต้องกดซ้ำ) |
| **A ●** | FC ยืนยันแล้ว (เซอร์โวขยับจริง) — กดซ้ำเพื่อปิด |
| **A 🔒** | รีโมทถือห้องอยู่ — UI สั่งไม่ได้ ต้องปิดสวิตช์ที่รีโมทก่อน |

### กติกาสำคัญ
- **1 ห้อง**: ช่องหนึ่งมีเจ้าของได้ทีละฝ่าย
- **A/B ยิงทันที ไม่มีกล่องยืนยัน** — สิ่งที่กันพลาดคือ toggle (กดซ้ำ=ยกเลิก),
  กติกา 1 ห้อง, โหมด REMOTE บล็อก, toast + Mission Log บันทึก
- โปรแกรมเตรียมช่อง A/B ให้เองอัตโนมัติหลังโดรนเข้าฝูง
  ใช้ค่าใน**ย่านปิด** ไม่ใช่ค่าเปิด → กลไกไม่ปล่อยของ

## 16. Leader Control (บังคับตัวแม่ตรง)

แผง **LEADER CONTROL** — คุมตัวแม่ตรง ลูกเกาะตามทันที (~0.4s):

| โหมด | วิธีใช้ |
|------|---------|
| **🖥 UI** | ตัวแม่เข้า GUIDED, ใช้ปุ่มทิศทาง (▲▼◄► ↺↻ ⤒⤓) กดค้าง=ไป ปล่อย=หยุด |
| **🎮 RC** | ตัวแม่เข้า LOITER, บังคับด้วยรีโมทจริง ลูกยังเกาะตาม |
| **■** (แดง) | หยุดทันที |

> ใช้ตอนฉุกเฉินเพื่อพาทั้งฝูงหลบ/นำไปจุดปลอดภัยได้เร็ว

## 17. สวิตช์ UI / REMOTE

สวิตช์บน Top bar ควบคุมว่าใครเป็นคนสั่งโดรน:

- **REMOTE** = มอบการควบคุมให้รีโมทจริง → **ล็อกคำสั่งบินทั้งหมดจาก UI ทันที**
  (Arm/Disarm/Takeoff/RC/Waypoint/RTL/Swarm กดไม่ติดทุกปุ่ม)
  + ขึ้น **banner สีเหลืองค้าง** จนกว่าจะสลับกลับ UI
  + กดปุ่มคำสั่งใด ๆ → banner เตือนซ้ำ

## 18. แผนที่ 2D

### พื้นฐาน

- วงแหวนทอง = Head/Leader
- เส้นขบวน แม่→ลูก (ขณะ Swarm)

## 19. แผนที่ 3D

### เปิดใช้
| ปุ่ม | ผลลัพธ์ |
|------|---------|
| **3D** | สลับแผนที่ในหน้าต่างเดิมเป็น 3D (กดซ้ำกลับ 2D) |

เปิดพร้อมกันทั้งสองบานได้ รับตำแหน่งโดรนชุดเดียวกัน

### การใช้งาน
- ลาก = หมุน · ล้อ = ซูม · **ดับเบิลคลิกพื้น = สั่งบินไปจุดนั้น**

ช่วยให้เห็นความต่างระดับในพื้นที่ราบ — **ห้ามเอาไปวัดความสูงจริง**

|------|-------|
| ความสูง | AWS Terrarium DEM |
| ภาพพื้น | Esri World Imagery (อันเดียวกับ 2D) |

ทั้งสองชั้นใช้กลไก tile cache/offline เดียวกับ 2D

## 20. Geofence (รั้วเขตบิน)

1. กด **DRAW FENCE** → คลิกวางจุดรอบพื้นที่ (≥ 3 จุด) → กด **SET**
2. รั้วแดงจะปรากฏ = core จะกันไม่ให้บินออก
3. **เพดานสูง/รัศมี**: ตั้งผ่าน env `SWARMGOD_MAX_ALT`, `SWARMGOD_MAX_RADIUS`

### Geofence Auto-Herd
ถ้าตั้งรั้วไว้ + โดรน armed แตะ/ข้ามเส้นแดง → core **ดึงกลับเข้าเขต 2m อัตโนมัติ**
(แต่ละลำดึงกลับที่จุดที่แตะ ระดับเดิม = ไม่ชนกัน) + แจ้งเตือน

## 21. Field Tablet (แท็บเล็ตสนาม)

### 21.1 คืออะไร
เว็บแอปสำหรับใช้บนแท็บเล็ตในสนาม เชื่อมต่อกับ cockpit ผ่าน **LAN เท่านั้น**
(ไม่ออกอินเทอร์เน็ต) ให้คนหน้างานดูสถานะและสั่งงานพื้นฐานได้

### 21.2 การเปิดใช้
1. ใน cockpit กดเมนู ⚙ → **เปิด Field Server** → ได้ PIN 6 หลัก
2. บนแท็บเล็ต เปิดบราวเซอร์ ไปที่ `http://<IP ของ cockpit>:8760`
3. ใส่ PIN → ได้ token เป็น **PILOT** (สั่งได้ทุกอย่าง) หรือ **VIEWER** (ดูอย่างเดียว + E-STOP/HOLD)

### 21.3 สิทธิ์ PILOT vs VIEWER

| สิทธิ์ | PILOT | VIEWER |
|--------|-------|--------|
| ดู telemetry + แผนที่ | ✅ | ✅ |
| E-STOP / HOLD | ✅ | ✅ |
| Waypoint / Swarm / GOTO | ✅ | ❌ |
| Movement (D-pad) | ✅ | ❌ |

VIEWER สั่ง HOLD/E-STOP ได้เสมอ — ห้ามกันออก (เพื่อความปลอดภัย)

### 21.4 หน้าจอ

```
┌──────────────────────────────────────────────────┐
│ [☰]                           [👁 ผู้ชม][● LAN] │
│                          ┌──────────────────────┐│
│   แผนที่เต็มจอ            │ ⌃ โดรน          (5) ││
│   (Leaflet + tile cache) │ ◆ Drone 1    0 m    ││
│                          │   กลุ่ม1 · GUIDED    ││
│                          │ ◆ Drone 2    0 m    ││
│                          └──────────────────────┘│
│ ┌──────────┐            ┌───────────────────────┐│
│ │ การ์ดลำ  │            │    แผงคำสั่ง (4 แท็บ) ││
│ │ ที่เลือก │            │                       ││
│ └──────────┘            └───────────────────────┘│
│ [E-STOP]          [FLIGHT] [WP] [SWARM] [MOVE]  │
└──────────────────────────────────────────────────┘
```

### 21.5 แท็บคำสั่ง (4 แท็บ)

**FLIGHT:**
- TAKEOFF / RTL / LAND / HOLD / ARM / DISARM
- Servo A / B
- Speed slider

**WAYPOINT:**
- เปิด/ปิด Waypoint Mode
- แตะแผนที่เพื่อวางจุด
- UNDO / CLEAR / EXECUTE ROUTE
- GROUPED / SEPARATE

**SWARM:**
- เปิด/ปิด Swarm
- เลือกรูปขบวน (WEDGE/LINE/COLUMN/DIAMOND/ECHELON)
- FORM UP / STOP SWARM / RETURN + LAND

**MOVE (D-pad):**
- ปุ่มทิศทาง 8 ทิศ + UP/DOWN
- ต้อง **ปลดล็อก** ก่อนใช้ (กัน false trigger)
- ความเร็วจำกัด ≤ 3 m/s (คอกพิตได้ 15)
- ปล่อยนิ้ว = หยุดทันที (deadman 1.2 วิ)
- ออกจากหน้า/สลับแท็บ = ส่ง move_stop อัตโนมัติ

### 21.6 Fleet Health (แถบสุขภาพฝูง)

ชิปสุขภาพบนแถบบน แสดงสถานะแย่ที่สุดในฝูง:
- **วิกฤต (แดงกะพริบ)**: BAT < 15% หรือ link > 10 วินาที → ชื่อลำ + สาเหตุ
- **เตือน (เหลือง)**: BAT ≤ 25% หรือ link > 3 วินาที → จำนวน + สาเหตุ
- **ปกติ (เขียว)**: ทุกลำดี

โดรนที่ critical จะมีกรอบแดงกะพริบ + badge บนแถบโดรน

### 21.7 การรับแจ้งเตือน
- **Toast**: แจ้งเตือนจาก cockpit ส่งมาแสดงบนแท็บเล็ตอัตโนมัติ
- **Dialog mirror**: เมื่อ cockpit มี modal เปิดอยู่ → แท็บเล็ตแสดง
  "คอมควบคุมกำลังถาม..." เพื่อให้รู้ว่ามีอะไรค้าง

### 21.8 ความปลอดภัย Field Tablet
- **LAN เท่านั้น** — ไม่เปิดออกอินเทอร์เน็ต, ห้าม port forward
- **Allowlist-only** — server มี whitelist คำสั่งที่อนุญาต ไม่ใช่ blocklist
- **ทุกคำสั่งผ่าน WebBridge → dispatch → เมธอดเดิม** ไม่ยิง gRPC ตรงจาก HTTP
- **ไม่แตะ Qt object จาก HTTP thread** — ผ่าน WebBridge เท่านั้น
- Rate limit: คำสั่งปกติ 2/วินาที, movement 10/วินาที (bucket แยก)

## 22. ความปลอดภัยของระบบ (Security)

### 6 ชั้นป้องกัน

| ชั้น | กลไก |
|------|------|
| 1. gRPC | mTLS + session token + bind localhost + idempotency |
| 2. Safety Envelope | ตรวจทุก command ก่อนส่ง: alt, distance, geofence, battery, GPS, spacing, speed, armed |
| 3. Confirm Dialog | คำสั่งเสี่ยง (KILL, DISARM กลางอากาศ, เปลี่ยน geofence) ต้อง double-action |
| 4. MAVLink Signing | HMAC-SHA256 กัน spoofing บน LAN/RF |
| 5. Failsafe | Link loss, battery critical, core crash → RTL/LAND อัตโนมัติ |
| 6. Audit Log | Append-only JSONL ทุกคำสั่ง + ผลลัพธ์ + เวลา |

### Safety Envelope ตรวจอะไรบ้าง
```
✓ Altitude      : 0 < alt ≤ MAX_ALT (default 120m)
✓ Distance       : ≤ MAX_RADIUS (default 500m จาก GCS)
✓ Geofence       : จุดเป้าต้องอยู่ในรั้ว
✓ Battery        : ห้าม takeoff ถ้า BAT < 25%
✓ GPS            : ห้าม arm/takeoff ถ้า fix < 3D หรือ SAT < 6
✓ Inter-drone    : goto/waypoint ห่างลำอื่น ≥ 5m
✓ Speed          : ≤ MAX_SPEED
✓ Armed          : goto/rc ต้อง armed + mode ถูกต้อง
```
ไม่ผ่าน → reject + reason กลับไป UI + เขียน audit (ไม่ส่งออกไปโดรน)

## 23. Failsafe อัตโนมัติ

### Core Failsafe (Go — ทำงาน 1 Hz)

| เหตุการณ์ | การกระทำ |
|-----------|---------|
| ไม่ได้รับ telemetry > 3 วินาที | mark RECONNECTING + alarm |
| ไม่ได้รับ > 10 วินาที | Link lost → RTL อัตโนมัติ |
| Battery < 15% | RTL อัตโนมัติ + alarm |
| โดรนแตะ/ข้ามเส้น Geofence | ดึงกลับเข้าเขต 2m |
| Command ไม่มี ACK | ถือว่าล้มเหลว + retry มีขอบเขต |

### FC-side Failsafe (ตั้งที่ Flight Controller — backstop เมื่อ core ดับ)
- `FS_THR_ENABLE` — สัญญาณ RC หาย
- `FS_GCS_ENABLE=1` — GCS หาย
- `BATT_LOW_VOLT` / `BATT_CRT_VOLT` — แรงดันต่ำ

> FC-side failsafe เป็นด่านสุดท้าย ต้องตั้งค่าเสมอ — ไม่พึ่ง core อย่างเดียว

## 24. การจัดการฉุกเฉิน

| สถานการณ์ | ทำ |
|-----------|-----|
| อยากให้ค้างกลางอากาศ | **HOLD** (ตรึงตำแหน่งใน GUIDED) |
| หยุดขบวน/เส้นทาง | **Cancel Nav** (หยุด + ค้างที่เดิม) |
| หยุด Swarm | **STOP** (swarm) |
| อันตรายเฉียบพลัน | **E-STOP** (Emergency Stop) — ดับมอเตอร์ทันที |
| สัญญาณขาด | Core failsafe RTL อัตโนมัติ (>10s) + FC failsafe เป็น backstop |
| แบตวิกฤต | Core สั่ง RTL อัตโนมัติ (<15%) + แถบเตือน |

### ลำดับความรุนแรง
```
HOLD (นิ่มสุด — ค้างที่เดิม)
  ↓
Cancel Nav (ตัด Waypoint + Hold)
  ↓
Emergency Stop (ตัด RTL + Waypoint + หยุดทันที — แรงที่สุด)
  ↓
E-KILL (ดับมอเตอร์ — โดรนตกทันที ใช้เมื่อจำเป็นจริง ๆ เท่านั้น)
```

> E-STOP และ HOLD ครอบทุกโหมด ไม่ว่าจะ RTL/Waypoint/Swarm กดได้หมด
> VIEWER บน Field Tablet ก็กด HOLD/E-STOP ได้เสมอ

## 25. แผนที่ความสัมพันธ์ระหว่างฟังก์ชัน

ปุ่ม/โหมดต่าง ๆ ถูกออกแบบให้ **กันชนกันเองอัตโนมัติ** — เปิดอันหนึ่ง
จะปิดอีกอันที่ขัดแย้งกันให้เอง ไม่ต้องกังวลว่ากดพร้อมกันแล้วจะพัง

### กลุ่ม "แตะแผนที่" — ใช้ได้ทีละระบบ
1. Waypoint Mode เปิด? → วางจุด
2. Tactical Tool เปิด? → วาดแผน
3. Geofence Draw เปิด? → วาดรั้ว
4. ไม่มีอะไรเปิด → สั่งบินตรง (Direct Flight)

เปิด Waypoint → ปิด Tactical + Geofence ให้เอง
เลือกเครื่องมือ Tactical/Geofence → ปิด Waypoint ให้เอง

### กลุ่ม "โหมดการบิน" — ผูกกันแน่น
- เปิด Swarm ระหว่าง SEPARATE → บังคับกลับ GROUPED ทันที
- กด SEPARATE ตอน Swarm เปิด → ถูกปฏิเสธ
- เปลี่ยน GROUPED ↔ SEPARATE → ล้างจุด Waypoint ค้าง

### กลุ่ม "ปุ่มหยุด/ยกเลิก" — ยิ่งแรงยิ่งตัดทุกอย่าง
- **Cancel Nav**: ตัด Waypoint Execute + ล้างเป้าหมาย + Hold
- **Emergency Stop**: ตัด RTL + Waypoint + หยุดทันที (แรงที่สุด)

### กลุ่มที่ไม่ผูกกัน (กดพร้อมกันได้)
เปลี่ยนสีโดรน · ตั้ง ALT/SPACING รายลำ · FLEET กับคลิกเลือก (sync) ·
ขยายฟอนต์ · Save/Load — UI ล้วน ไม่แตะ state การบิน

## 28. การแก้ปัญหาเบื้องต้น (Troubleshooting)

### ปัญหาที่พบบ่อย

| อาการ | สาเหตุ | แก้ไข |
|-------|--------|-------|
| Badge ค้าง OFFLINE | IP/port ผิด หรือ FC ไม่ได้เปิด | ตรวจ IP/port, ลอง PING |
| SAT ขึ้นน้อย / ไม่ล็อก 3D | GPS ยังไม่ converge | รอ 30–60 วินาที ที่กลางแจ้ง |
| ARM ถูกปฏิเสธ | Pre-arm check ไม่ผ่าน (EKF, GPS, BAT) | ดู toast/Mission Log สำหรับ reason |
| ARM ล้มเหลวช่วง SITL boot | EKF ยัง converge ไม่เสร็จ | รอ ~60 วินาทีหลัง SITL boot |
| กดปุ่มไม่ติด | อยู่โหมด REMOTE | สลับกลับเป็น UI ที่สวิตช์บน Top bar |
| เปลี่ยน Head ไม่ได้ | กำลัง RTL/TAKEOFF/LANDING/Swarm เคลื่อนที่ | รอจนนิ่งก่อน |
| UNIMPLEMENTED method | Core binary เก่า | `cd backend && go build ./...` แล้ว restart core |
| Field Tablet เชื่อมไม่ได้ | ไม่ได้เปิด Field Server หรืออยู่คนละ LAN | ตรวจ ⚙ → เปิด Field Server, ตรวจ IP |
| หน้าเว็บกดแล้วไม่ไป | กำลังเป็น VIEWER | ขอ PILOT token (ใส่ PIN ใหม่ในฐานะ PILOT) |

### ไฟล์ log สำคัญ

| ไฟล์ | เนื้อหา |
|------|---------|
| `backend/logs/core-YYYYMMDD.log` | Log หลักของ core |
| `backend/logs/core-stdout.log` | stdout/stderr ดิบจาก launcher |
| `backend/logs/audit/audit-YYYYMMDD.jsonl` | Audit ทุกคำสั่ง |
| `backend/logs/swarmgod.db` | SQLite (fleet, index) |

### รีเซ็ตแบตเตอรี่ SITL
เมื่อตัวจำลองใช้แบตจน safety gate ไม่ยอมให้ Arm:
เลือกโดรน → เมนูจุด 3 จุดบนหัวแผง COMMANDS → **รีเซ็ตแบตเตอรี่จำลอง (SITL)…**
→ ใส่แรงดัน → ยืนยัน

> ใช้เฉพาะ SITL ต้อง Disarm ก่อน ห้ามใช้กับโดรนจริง
