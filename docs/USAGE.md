# SwarmGod — คู่มือใช้งานจริง (ตั้งแต่เริ่มจนพร้อมบิน)

คู่มือนี้อธิบาย **ลำดับขั้นการใช้งานกับโดรนจริง** ว่าเชื่อมอะไรก่อน-หลัง
ทำตามทีละข้อจนถึง "พร้อม takeoff"

> ⚠️ อ่าน `docs/RUNBOOK.md` (Pre-flight โดรนจริง) และ `docs/SECURITY.md` ก่อนบินจริงเสมอ

---

## 🔧 ก่อนออกสนาม (เตรียมล่วงหน้าที่บ้าน)

| เตรียม | รายละเอียด |
|--------|-----------|
| **ฮาร์ดแวร์** | โดรนแต่ละลำมี Flight Controller + GPS + ตัวส่ง telemetry (WiFi/วิทยุ/4G) |
| **เครือข่าย** | โดรนทุกลำ + GCS อยู่วงเดียวกัน, จด **IP:port** แต่ละลำ (เช่น `192.168.40.1:5760`) |
| **certs** | รัน launcher หนึ่งครั้ง (สร้าง mTLS + signing key) หรือ `go run ./cmd/gencerts` |
| **MAVLink signing** | ถ้าจะเปิด strict — เอา `certs/mavlink_key` ไปตั้งที่ FC ให้ตรงกัน |
| **FC failsafe** | ตั้งที่ FC: `FS_GCS_ENABLE=1`, `FS_THR_ENABLE`, `BATT_LOW/CRT_VOLT` |
| **แผนที่ offline** | ถ้าสนามไม่มีเน็ต — เปิดโปรแกรมที่บ้าน กด CACHE THIS AREA เก็บ tiles พื้นที่ปฏิบัติงานไว้ |

## ▶️ ลำดับการใช้งาน (เริ่ม → พร้อมบิน)

### ขั้น 1 — เปิดโปรแกรม
- ดับเบิลคลิก **`START_SWARMGOD.bat`** → **เอาเครื่องหมาย ✕ ออกจาก "ใช้ SITL"** (เพราะใช้โดรนจริง)
- launcher จะ: สร้าง certs → เปิด **core** (mTLS + signing) → เปิด **cockpit**
- รอ checklist ขึ้น "✅ พร้อมใช้งาน" แล้วหน้าต่าง cockpit เด้งมา

### ขั้น 2 — เชื่อมต่อโดรน (ทีละลำ) 🔌
> **เชื่อม core ก่อน (ทำอัตโนมัติ) → แล้วค่อยเชื่อมโดรนทีละลำผ่าน cockpit**

1. ช่อง IP บนซ้าย พิมพ์ **IP ของลำที่ 1** (เช่น `192.168.40.1`) + PORT (`5760`) → กด **CONN**
   - หรือกด **SCAN** เพื่อหาพอร์ต MAVLink ในวง LAN แล้วเลือกใส่
   - IP ที่เคย add จะถูกจำใน SQLite (`~/.swarmgod/fleet_ips.db`) — เปิดครั้งหน้าขึ้นเอง
   - IP ซ้ำกับลำอื่นจะถูกปฏิเสธพร้อม toast เตือน
2. การ์ด **UAV_1** โผล่ทางซ้าย → badge จะไล่: `OFFLINE → CONNECTING → READY`
3. ทำซ้ำสำหรับลำ 2, 3, … (เปลี่ยน IP/port เช่น `192.168.40.2:5760`)
4. บนการ์ด: **PING** ทดสอบลิงก์ · **DISC** ตัดการเชื่อม · **DEL** ลบออกจากฝูง
5. เมนู/ปุ่ม **SAVE / EXPORT / LOAD** เก็บหรือย้ายการตั้งค่า cockpit (JSON)

### ขั้น 3 — ตรวจ telemetry ทุกลำ (สำคัญที่สุดก่อนบิน) ✅
ดูที่การ์ดแต่ละลำ ต้องครบ:
- **badge = READY** (เขียว)
- **SAT ≥ 6 + 3D** (GPS ล็อกแล้ว) — ถ้ายัง `no`/ตัวเลขน้อย ให้รอ
- **BAT** พอ (แนะนำ > 50%; core ห้าม arm ถ้า < 25%)
- **MODE / ALT / HDG** ขึ้นค่าจริง + หมุดโดรนโผล่บนแผนที่ตรงตำแหน่ง

#### อ่านหน้าจอ Cockpit

- ป้ายเล็ก **CORE** บนแถบบน = core พร้อมทำงาน · **LINK OK** = cockpit กำลังได้รับ telemetry
- การ์ดล่างของลำที่เลือกแสดงโมเดลโดรน, สถานะ, link quality, battery และคำสั่งรายลำ กด **✎** เพื่อแก้ชื่อโดรนและบันทึกกับ endpoint เดิม
- แถบ **LAT/LNG** ใต้แผนที่จะย่อให้พอดีกับหน้าต่างโดยไม่ดันแผงคำสั่งออกนอกจอ หากข้อความถูกตัดให้ชี้เมาส์ค้างเพื่อดูค่าเต็ม
- ปุ่ม **3D** สลับแผนที่เดิมเป็น 3 มิติ · **3D ⧉** เปิดหน้าต่างแยกสำหรับจอที่สอง
- ใน Map 3D การ์ด **โดรน** มุมขวาบนแสดงสีประจำลำ ความสูง และโหมดบิน กดลูกศรเพื่อพับ/กาง และคลิกรายการเพื่อเลือกโดรนได้ทันที
- **Mission Log** มีแถบเครื่องมือสองแถวคงที่ ไม่มีการเลื่อนแนวนอน โดยแถวบนเลือกประเภท **All / Commands / Alerts / Telemetry** และมีตัวกรอง **System** หรือรายโดรนอยู่ด้านล่าง

### ขั้น 4 — ตั้งค่าความปลอดภัย (ก่อน takeoff) 🛡️
- **Geofence**: กด **DRAW FENCE** → คลิกวางจุดรอบพื้นที่ (≥3 จุด) → **SET** (รั้วแดง = core จะกันไม่ให้บินออก)
- **เพดานสูง / รัศมี**: ตั้งผ่าน env ของ core `SWARMGOD_MAX_ALT`, `SWARMGOD_MAX_RADIUS` ให้ตรงข้อกำหนดพื้นที่
- ตรวจว่าพื้นที่โล่ง คน/สิ่งกีดขวางออกห่าง

> **Geofence auto-herd**: ถ้าตั้งรั้วไว้ + โดรน armed แตะ/ข้ามเส้นแดง → core **ดึงกลับเข้าเขต 2m อัตโนมัติ**
> (แต่ละลำดึงกลับที่จุดที่แตะ ที่ระดับเดิม = ไม่ชนกัน) + แจ้งเตือน "แตะเส้นเขต"

### ขั้น 5 — บิน 🚁
> **สั่งทีละลำได้**: การ์ดแต่ละลำมี ALT (ความสูงแยก) + ปุ่ม **TAKEOFF/RTL/LAND** ของตัวเอง
> เช่นอยากให้ Drone 2 ขึ้น → กด TAKEOFF ที่การ์ด Drone 2 (ไม่กระทบลำอื่น)

1. เลือกลำเป้าหมาย (การ์ด/target) หรือใช้ปุ่มบนการ์ดแต่ละลำ
2. ตั้ง **TAKEOFF ALT** (เช่น 20) = ความสูงเป้าหมายหลังขึ้นบิน → กด **▲ TAKEOFF** → รอ badge `FLYING` + ALT ไต่ถึงระดับ
3. บังคับ:
   - ปลดล็อกปุ่มรูปโดรนบนแผนที่ก่อน แล้ว **คลิกแผนที่ 2D / ดับเบิลคลิกพื้น 3D** = บินไปจุดนั้น (GOTO)
   - **GO TO ALT** = เปลี่ยนความสูง
   - **HOLD** = ค้างที่เดิม · **RTL** = กลับ home · **LAND** = ลงตรงนี้

### ขั้น 6 — จัดขบวน (ถ้าบินเป็นฝูง) 🐝
1. ให้ทุกลำ **takeoff ขึ้นก่อน** (badge FLYING ครบ)
2. เลือก **รูปขบวน** (WEDGE/LINE/COLUMN/DIAMOND/ECHELON) + ตั้ง **SEP** (ระยะห่าง)
3. กด **FORM UP** → ลูกจัดตำแหน่งเกาะตัวแม่ + **หันหน้าตามตัวแม่**
   - ถ้าตั้ง SEP ใกล้เกินขั้นต่ำ → **เตือนสีเหลือง + ไม่ให้ตั้ง**
   - ตัวแม่ (UAV_1) หาย → เลื่อนตัวถัดไปเป็นแม่อัตโนมัติ (★ LEADER ย้ายเอง)
4. เปลี่ยนรูป/ระยะระหว่างบินได้ — กด FORM UP ใหม่

> **SPACING** บนการ์ดล่าง = ระยะห่างจากลำหน้าขณะบินเป็นขบวน ไม่ใช่ความสูงและไม่ใช่ระยะทางไปยังจุด GOTO

### กลุ่มโดรนและ WAVE

- แถว **กลุ่ม** เหนือรายการโดรนมีชิป **ทั้งหมด / 1–6** โดยรูปแบบ `1·2` หมายถึง “กลุ่ม 1 มี 2 ลำ” ตัวเลขใช้ขนาดปกติเพื่อให้เห็นชัดแม้ Windows ขยายหน้าจอ
- คลิกชิปเพื่อเลือกทั้งกลุ่ม หรือ Ctrl+คลิกเพื่อเพิ่มอีกกลุ่ม โดยลำที่ offline จะถูกข้ามพร้อมแจ้งเตือน
- กำหนดกลุ่มด้วย Ctrl+เลข 1–6, คลิกขวาที่ชิป หรือคลิกขวาที่การ์ดโดรนแล้วเลือก **กลุ่ม**
- กลุ่มเป็นเพียงชุดการเลือก ไม่ส่งคำสั่งบินเอง และโดรนหนึ่งลำอยู่ได้กลุ่มเดียว

ใน **WAYPOINT ROUTE / GROUPED** เปิด WAVE แล้วเลือกอย่างน้อย 2 กลุ่ม เมื่อกด **EXECUTE ROUTE** ระบบจะส่งกลุ่มตามเลข 1 → 2 → 3 กลุ่มละรอบ หลังบินครบจะกลับฐานและลงจอด โดยกลุ่มถัดไปจะยังไม่เริ่มจนกลุ่มเดิม Disarm ครบ หากเกิน 5 นาที ระบบหยุดทั้ง WAVE

ก่อนเริ่มเส้นทาง ระบบตรวจ telemetry ของโดรนเป้าหมายทุกลำ หากยังไม่ TAKEOFF จะถามว่าจะขึ้นบินหรือไม่ พร้อมแสดงรายชื่อและความสูง เมื่อยืนยัน ระบบสั่ง TAKEOFF แล้วรอจนทุกลำ Armed และสูงพ้นพื้นอย่างน้อย 1.5 เมตรจึงเริ่ม GOTO (รอไม่เกิน 90 วินาที) ใน WAVE จะตรวจใหม่ก่อนเริ่ม **ทุกกลุ่ม** ดังนั้นกลุ่มที่บินอยู่แล้วจะเริ่มต่อโดยไม่ถาม ส่วนกลุ่มที่ยังอยู่พื้นจะถามเฉพาะกลุ่มนั้น

คลิกขวาที่จุด Waypoint หรือรายการจุดในแผงขวาเพื่อเลือก **ปล่อย A (CH7) / ปล่อย B (CH8) / ไม่ทำอะไร** จุด A/B จะแสดงสีต่างกัน เมื่อถึงจุดระบบ HOLD ก่อนปล่อย รอ 2 วินาที แล้วจึงไปจุดถัดไป ทุกเส้นทางที่มีการปล่อยของต้องยืนยันรายละเอียดก่อน EXECUTE เสมอ

> WAVE ไม่เปลี่ยนพฤติกรรมของปุ่ม TAKE OFF, RTL, LAND, GOTO, ARM, HOLD หรือ E-STOP แต่ EXECUTE ROUTE สามารถสั่ง TAKEOFF ให้กลุ่มที่ยังอยู่พื้นได้ **หลังผู้ใช้ยืนยันเท่านั้น** และยกเลิก WAVE ได้จาก **ยกเลิกเวฟ**, Cancel Nav, ปิด WAVE หรือ E-STOP

### PRE-FLIGHT SUMMARY

กล่อง **PRE-FLIGHT SUMMARY** มีสองส่วน:

- **FLIGHT PLAN** คือค่าที่จะมีผลจริงกับเที่ยวบิน เรียงคงที่เป็น TARGET, HEAD,
  TAKEOFF, SWARM, WAYPOINT, PAYLOAD A/B, WAVE, RETURN PLAN และ GEOFENCE
- **EXECUTION FLOW** คือ timeline ของ operation ปัจจุบัน บอก `ACTIVE`, `NEXT`,
  detail สด และผลสุดท้ายของแต่ละขั้น

กด TAKEOFF, SWARM TAKEOFF, EXECUTE ROUTE หรือ WAVE แล้วระบบจะ freeze **RUN
SNAPSHOT** ของ Flight Plan นั้นไว้จนจบหรือกด Clear จึงตรวจย้อนดูได้ว่าเริ่มบินด้วย
ค่าใด การเปลี่ยนแผนที่หน้าจอภายหลังจะไม่แก้ snapshot เดิม

ประวัติคำสั่ง เช่น Cancel Nav, Undo/Clear Waypoint, Stop Swarm, Servo,
SYSTEM TEST, CHECKLIST และผลคำสั่ง ดูที่ **MISSION LOG > COMMAND** เท่านั้น
ไม่ปนกับ Flight Plan

### รีเซ็ตแบตเตอรี่ระหว่างซ้อม SITL

เมื่อตัวจำลองใช้แบตจน safety gate ไม่ยอมให้ Arm ให้เลือกโดรนจำลองที่ต้องการ แล้วเปิดเมนู **จุดสามจุดบนหัวแผง COMMANDS** → **รีเซ็ตแบตเตอรี่จำลอง (SITL)…** → ใส่แรงดันและยืนยัน

> ใช้เฉพาะ SITL และต้อง Disarm ก่อน เมนูนี้ตั้งค่า `SIM_BATT_VOLTAGE` ที่ Flight Controller จึงห้ามใช้กับโดรนจริง

### บังคับตัวแม่โดยตรง (ฉุกเฉิน / นำขบวนแบบสด) 🕹️
แผง **LEADER CONTROL** — คุมตัวแม่ตรงๆ ลูกๆ เกาะตามทันที (~0.4s):
- กด **🖥 UI** → ตัวแม่เข้า GUIDED, ใช้ **ปุ่มทิศทาง** (▲▼◄► + ↺↻ หมุน + ⤒⤓ ขึ้นลง) แบบ **กดค้าง=ไป ปล่อย=หยุด**
- กด **🎮 RC** → ตัวแม่เข้า LOITER, บังคับด้วย **รีโมทจริง** (transmitter) ที่ผูกกับ FC ของตัวแม่ — ลูกยังเกาะตาม
- ปุ่ม **■** (แดง) = หยุดทันที
> ใช้ตอนฉุกเฉินเพื่อพาทั้งฝูงหลบ/นำไปจุดปลอดภัยได้เร็ว โดยคุมแค่ตัวแม่ตัวเดียว

### ขั้น 7 — จบภารกิจ 🛬
- **รายลำ**: กด **RTL / LAND** บนการ์ดของลำนั้น
- **ทั้งฝูงแบบกันชน**: กด **⏎ RETURN + LAND** (ในแผง SWARM):
  1. ทุกลำบินไปเหนือ**จุดลงแยกของตัวเอง**รอบ home โดยชั้นความสูงและจุดลงห่างกันไม่น้อยกว่า MinSeparation (ค่าเริ่มต้น 5m)
  2. **ลงจอดทีละลำ ตัวแม่ก่อน** แล้วลูกๆ ตามลำดับ (ลำก่อนแตะพื้นและ disarm ค่อยลำถัดไป)
- รอ badge → `DISARMED`

## 🚨 ฉุกเฉิน
| สถานการณ์ | ทำ |
|-----------|-----|
| อยากให้ค้างกลางอากาศ | **HOLD** (ตรึงตำแหน่งใน GUIDED) |
| หยุดขบวน | **STOP** (swarm) |
| อันตรายเฉียบพลัน | **⚠ EMERGENCY KILL** — ดับมอเตอร์ทันที (โดรน**ตกทันที** ใช้เมื่อจำเป็นจริง) |
| สัญญาณขาด | core **failsafe RTL อัตโนมัติ** (>10s) + FC-side failsafe เป็น backstop |
| แบตวิกฤต | core สั่ง RTL อัตโนมัติ (< 15%) + แถบเตือน |

## ✅ Checklist ก่อน takeoff (สรุปสั้น)
```
[ ] core ขึ้น [mTLS + signing]
[ ] ทุกลำ badge READY
[ ] ทุกลำ SAT ≥ 6 + 3D fix
[ ] ทุกลำ BAT เพียงพอ
[ ] GCS location + geofence + alt limit ตั้งแล้ว
[ ] FC-side failsafe params ตั้งแล้ว
[ ] พื้นที่โล่ง คนออกห่าง ลมไม่แรงเกิน
```

## หมายเหตุการเชื่อมต่อ
- **โปรโตคอล**: TCP หรือ UDP (MAVLink) — ปกติโดรนจริงเปิด TCP `<ip>:5760`
- ถ้าใช้ MAVProxy/ตัวรีเลย์กลาง: เชื่อมไปที่ port ที่รีเลย์เปิดให้ (เช่น UDP 14550)
- **ลำดับสำคัญ**: core (พร้อม) → เชื่อมโดรนทีละลำ → รอ GPS → ตั้ง safety → บิน
